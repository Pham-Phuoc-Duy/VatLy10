# 📐 Tổng hợp công thức Vật Lý 10

## Động học

| Nội dung | Công thức |
|---|---|
| Vận tốc trung bình | $v_{tb} = \dfrac{d}{t}$ |
| Gia tốc | $a = \dfrac{\Delta v}{\Delta t}$ |
| Chuyển động thẳng biến đổi đều | $v = v_0 + a t$ ; $d = v_0 t + \frac{1}{2} a t^2$ ; $v^2 - v_0^2 = 2 a d$ |
| Rơi tự do | $v = g t$ ; $s = \frac{1}{2} g t^2$ |
| Ném ngang | $L = v_0 \sqrt{\dfrac{2h}{g}}$ |

## Động lực học

| Nội dung | Công thức |
|---|---|
| Định luật 2 Newton | $\vec{F} = m \vec{a}$ |
| Trọng lực | $P = m g$ |
| Lực ma sát trượt | $F_{ms} = \mu N$ |
| Moment lực | $M = F d$ |

## Năng lượng – Động lượng – Chuyển động tròn

| Nội dung | Công thức |
|---|---|
| Công | $A = F s \cos\alpha$ |
| Công suất | $\mathcal{P} = \dfrac{A}{t}$ |
| Động năng | $W_đ = \frac{1}{2} m v^2$ |
| Thế năng trọng trường | $W_t = m g h$ |
| Hiệu suất | $H = \dfrac{A_{ci}}{A_{tp}} \cdot 100\%$ |
| Động lượng | $\vec{p} = m \vec{v}$ |
| Tốc độ góc | $\omega = \dfrac{2\pi}{T} = \dfrac{v}{r}$ |
| Gia tốc hướng tâm | $a_{ht} = \dfrac{v^2}{r} = \omega^2 r$ |
| Định luật Hooke | $F_{đh} = k \lvert \Delta l \rvert$ |
| Áp suất chất lỏng | $p = p_a + \rho g h$ |
